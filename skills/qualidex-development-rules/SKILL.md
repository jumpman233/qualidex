# Qualidex Development Rules

Before making code or test changes in this repository, read `../../AGENTS.md` first. It is the highest-level repository instruction entrypoint.

Then read `../../docs/development-rules.md` when you need testing, validation, E2E, or development workflow details.

Project documentation should be written in Chinese by default. Keep code identifiers, file names, script names, and technical API names in English when appropriate.
