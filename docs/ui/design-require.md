# Qualidex 前端页面设计要求（更新版）

> 基于 electron-vite + React + TypeScript 实现  
> Windows 本地人员资料归档与资质查询工具  
> 用户主要是非技术人员  

页面风格参考 Notion / 飞书工作台 + ChatGPT 输入框，保持单页工作台，避免复杂后台样式。

---

## 页面结构

整体为单页 AppShell：

1. **顶部栏**
   - 左侧显示 Qualidex
   - 副标题：人员资料归档与资质查询工具
   - 右侧显示 当前资料库、设置、帮助

2. **智能操作区 CommandBar**
   - 大输入框
   - placeholder 示例：
     - 找成都 3 个大专以上、有二建证、资料齐全的人
     - 新增一批工程类成都资料
     - 处理待确认资料
   - 快捷按钮：
     - 查询人员
     - 新增资料
     - 查看待确认
     - 导出记录

3. **状态概览区 OverviewCards**
   - 已整理人员
   - 待确认资料
   - 最近新增
   - 导出记录

4. **主工作区 MainWorkspace**
   根据 `workspaceMode` 切换：
   - home
   - search
   - import
   - review
   - export

## 查询模式 search

- 用户输入自然语言后，先展示“系统理解的查询条件”卡片。
- 条件卡片字段：
  - 类别（支持多选）
  - 地区
  - 人数
  - 学历
  - 证书
  - 资料完整度
  - 是否包含待确认
  - 导入批次
  - 是否包含多人员资料
- 按钮：
  - 确认查询
  - 修改条件

**人员结果卡片字段：**
- 勾选框
- 姓名_唯一标识
- 类别 / 地区 / 学历 / 证书
- 资料完整度
- 是否有关联多人员资料
- 是否包含待确认资料
- 匹配原因（高亮关键字段）
- 状态标签（柔和色彩 + 图标）
- 操作按钮：查看资料、打开文件夹、加入导出

---

## 新增资料模式 import

- 资料类别下拉框：工程 / 环境 / 消防员 / 自动识别
- 地区输入框或下拉框
- 选择文件夹按钮
- 开始整理按钮

**整理进度显示：**
- 扫描文件
- 识别文字
- 分析文件夹关系
- 整理人员
- 生成待确认
- 生成归档预览

**整理完成后 CTA：**
- 有待确认资料：
  - 主按钮：处理待确认资料
  - 次按钮：查看本次新增人员
  - 次按钮：稍后处理
- 无待确认资料：
  - 主按钮：生成归档预览
  - 次按钮：查看本次新增人员
  - 次按钮：继续新增资料

**新增文件夹处理逻辑：**
- 对同一文件夹内所有文件进行整体分析
- 判断人员归属，生成待确认项
- 更新数据库关联

---

## 待确认模式 review

**卡片字段：**
- 问题类型
- 文件名
- 系统猜测结果
- 原因
- 查看文件按钮
- 打开所在文件夹
- 查看识别文字按钮
- 查看关联文件
- 可编辑字段：
  - 类别
  - 地区
  - 人员
  - 资料类型
  - 证书名称
  - 证书认可状态
  - 官方 / 非官方标签
  - 颁发机构可信度（仅人工标记）

**操作按钮：**
- 确认
- 跳过
- 标记为无法识别

---

## 导出模式 export

**导出预览字段：**
- 本次导出人员列表
- 导出内容选择：
  - 人员清单 Excel
  - 人员资料文件夹
  - 是否包含多人员共用资料
  - 身份证号导出方式（默认脱敏 / 用户选择完整）
- 导出位置
- 风险提示：
  - 多人员共用资料可能包含非本次人员信息
  - 导出完整身份证号需确认使用场景

**按钮：**
- 开始导出
- 修改选择
- 取消

## 设置入口

- 类别管理（默认内置 + 配置化维护）
- 地区管理
- 证书官方 / 非官方标签维护
- 颁发机构可信度人工标记维护
- 导出安全设置
- 资料库路径设置

---

## 视觉风格

- 背景浅灰
- 主内容白色圆角卡片
- 卡片间距充足
- 字体层级清晰
- 少用强颜色
- 状态标签柔和颜色 + 图标
- 危险操作红色提示
- 主按钮醒目但不刺眼

---

## 技术要求

- React + TypeScript
- 组件化拆分
- 使用 mock data 实现静态交互
- 暂不接入真实 Electron API
- useState 即可，无需复杂状态库
- Electron 主进程能力通过 service 层接入

## 数据安全与人工确认规则

- 身份证号默认脱敏展示
- 本地保存完整身份证号
- 云端 AI 不上传完整身份证号
- 导出身份证号默认脱敏，用户选择才导出完整
- 多人员共用资料在查询、详情、导出中明确提示
- 颁发机构可信度仅人工标记，AI 和代码逻辑不介入
