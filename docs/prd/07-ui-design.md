# Qualidex PRD 拆分文档

> 来源：Qualidex PRD V1.4  
> 产品形态：Windows 本地桌面工具  
> 技术栈：Electron + electron-vite + React + TypeScript + SQLite + sqlite-vec + 本地 OCR + 云端文本 AI API

## 19. 页面设计

### 18.1 页面整体方向

前端采用单页工作台设计：

```text
Notion / 飞书式结构化工作台
+
ChatGPT / Cursor 式自然语言输入框
+
卡片式确认
+
查询导出优先
```

面向非技术用户，页面上避免直接暴露：

```text
import_batch
OCR pipeline
AI extraction
archive job
SQLite
```

应使用：

```text
导入资料
整理资料
待确认
查询人员
导出结果
```

### 18.2 数据源与导入页

功能：

- 选择原始资料目录
- 选择归档输出目录
- 选择数据库文件
- 选择导入方式：
  - 首次全量导入
  - 新增文件夹
  - 重新扫描指定文件夹
- 手动指定主类别
- 手动指定地区
- 开始导入

### 18.3 扫描处理页

展示：

- 当前导入批次
- 总文件数
- 新增文件数
- 重复文件数
- OCR 成功数
- OCR 失败数
- AI 抽取成功数
- 待确认数量
- 当前处理文件
- 错误列表

操作：

- 开始
- 暂停
- 继续
- 停止
- 重新处理失败项

### 18.4 待确认页

功能：

- 待确认列表
- 按类型筛选
- 查看文件
- 查看 OCR 文本
- 查看 AI 抽取结果
- 修改结构化信息
- 显示证书官方 / 非官方标签
- 手动设置证书官方 / 非官方标签
- 确认
- 批量处理

MVP 第一版可采用卡片式确认。

证书官方 / 非官方标签展示与交互：

- 每个证书候选项显示一个状态标签：官方、非官方、未判断。
- 默认显示为“未判断”，对应数据库 `licenses.official_status = null`。
- 用户可在证书候选卡片上手动改为“官方”或“非官方”，也可清空恢复为“未判断”。
- 交互控件可使用分段选择器、下拉选择器或三态标签按钮；正式实现前以页面信息可见为优先。
- AI / OCR 结果只能作为旁边的证据或待确认原因展示，不得自动把标签设为“官方”或“非官方”。
- 用户修改该标签时，应写入操作日志。

### 18.5 人员详情页

展示：

- 基本信息
- 主类别 / 地区
- 学历
- 证书
- 证书官方 / 非官方标签
- 关联文件
- 多人员资料
- 待确认项
- 操作日志

操作：

- 编辑人员
- 合并人员
- 拆分人员
- 打开归档文件夹
- 重新生成该人员归档
- 删除人员

人员详情页中的每条证书记录都应显示官方 / 非官方标签。交互未实现前，至少在证书列表中显示“官方 / 非官方 / 未判断”，避免用户误以为系统已经完成判断。

### 18.6 查询页

功能：

- 自然语言查询框
- AI 解析结果确认
- 类别多选条件展示
- 证书候选确认
- 高级筛选
- 候选人员列表
- 导出操作

查询结果中的证书信息应展示官方 / 非官方标签。高级筛选后续可扩展为按“官方、非官方、未判断”筛选，但默认查询不得把 `null` 当作“非官方”。

### 18.7 类别筛选控件

查询页中的类别筛选应支持多选。

可选项：

```text
工程
环境
消防员
未识别类别
```

展示方式：

```text
类别：[工程] [消防员]
```

修改条件时，使用多选下拉或标签选择器。

交互要求：

- 可同时选择多个类别。
- 默认查询逻辑为 OR。
- 用户可一键清空类别条件。
- 未选择类别时，表示不限制类别。
- 类别条件只影响查询筛选，不直接改变归档目录。

### 18.8 导出页

功能：

- 查看导出记录
- 打开导出目录
- 重新导出
- 查看人员清单
- 查看导出日志

### 18.9 回收站页

功能：

- 查看已删除人员
- 查看已删除文件
- 恢复
- 清理归档副本
